# МойНалог (ip-uchet)

Вертикальный SaaS-MVP: **учёт доходов и налогов для ИП и самозанятых** (Россия). Каждый пользователь видит только свои данные.

## Возможности MVP

- Регистрация/вход (email + пароль, scrypt-хеш, подписанная cookie-сессия)
- Доходы: дата, сумма, категория, плательщик (физлицо 4% / компания 6% для НПД), номер чека, способ оплаты
- Расходы: дата, сумма, категория
- Дашборд: доходы/налог по месяцам, ближайшие сроки уплаты, лимит НПД (2,4 млн ₽/год)
- Налоговые режимы: **НПД** (4%/6%, вычет 10 000 ₽, до 28-го след. месяца), **УСН 6%** (взносы ИП уменьшают налог до 100%), **УСН 15%** (доходы − расходы)
- Экспорт доходов/расходов за год в CSV
- Хранение: JSON-файл `data/db.json` (в .gitignore)

Без внешних зависимостей: Node.js + TypeScript + встроенные модули (`node:http`, `node:crypto`).

## Запуск

```bash
npm install
cp .env.example .env     # задайте SESSION_SECRET (openssl rand -hex 32)
npm run dev              # http://localhost:3000
# продакшн: npm run build && npm start
```

## API

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/register` | `{email, password}` → сессия |
| POST | `/api/login` | `{email, password}` → сессия |
| POST | `/api/logout` | сброс сессии |
| GET | `/api/me` | текущий пользователь + профиль |
| PUT | `/api/profile` | `{regime: npd\|usn6\|usn15, status: self\|ip, fixedContributions}` |
| GET/POST | `/api/entries` | список/создание (`type=income\|expense`) |
| DELETE | `/api/entries/:id` | удалить |
| GET | `/api/summary?year=2026` | сводка по году: месяцы, налог, сроки, лимит |
| GET | `/api/export.csv?type=income&year=2026` | CSV |

Все `/api/*` кроме register/login требуют сессию (cookie).
